# Media

Drop project artwork here. Filenames must match `poster` / `video` in `lib/projects.ts`.

- `card-stack.jpg` . Poster still, ~1600x1000
- `card-stack.mp4` . Screen recording, 8-15s, muted, under ~4MB
- `split-screen.jpg`
- `ios-app.jpg`

Record at 2x and downscale so text stays crisp. Until files exist, the carousel
shows a hatched placeholder. Nothing breaks.
